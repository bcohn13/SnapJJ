# SnapJJ

Snapjj is a tool that analyzes screenshots of your jiu jitsu match and provides you with insights.


<h3>How to install</h3>

<p>1) Clone the repository</p>
<code>git clone https://github.com/bcohn13/SnapJJ.git</code>

<br/>
<br/>
<p>2) Run the setup script</p>

<code>python setup.py sdist</code>

<br/>
<br/>
<p>3) Pip install the tarball</p>
<code>pip install ./dist/snapjj.tar.gz</code>

<br/>
<br/>
<p>4) Start using the tool on a screenshot image of you in your jiu jitsu match</p>
<code>snapjj image.png</code>

<br/>
<h3>Have fun!</h3>
